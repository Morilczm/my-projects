## Formula Region Contract

Detected formula regions include page number, bounding box, image-region hash,
detection method, detection confidence, surrounding text references, source page
reference, recognizer routing status, recognizer identity fields, empty
LaTeX/MathML candidates, abstention reason, and provenance metadata.

Detection and recognition remain separate:

```text
formula image region detected -> FORMULA_RECOGNIZER_UNAVAILABLE
```

No ordinary Tesseract OCR output is treated as LaTeX or formula recognition.

## False Positive And False Negative Notes

- Plain scanned text did not produce formula regions.
- Born-digital text did not produce formula image regions.
- Mixed-layout non-formula imagery did not produce formula regions.
- The detector is conservative; it can miss formula images that are not
  symbol-dense enough for the current raster heuristic.
