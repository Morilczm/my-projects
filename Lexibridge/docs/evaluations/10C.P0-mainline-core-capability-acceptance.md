## OCR Acceptance

The three image-only PDF fixtures had no text layer and were blocked before governed source creation:

- `scanned-english.pdf`: OCR required, no OCR text, no Formal Run.
- `scanned-chinese.pdf`: OCR required, no OCR text, no Formal Run.
- `scanned-bilingual.pdf`: OCR required, no OCR text, no Formal Run.

Current measured recall:

- Clear English scanned terms: `0/10`
- Clear Chinese scanned terms: `0/10`
- Scanned explicit bilingual pairs: `0/5`

This is a product-mainline blocker before real Provider registration because image-only course PDFs cannot reach governed source, candidate governance, or Formal Item preparation.

## Formula Boundary

The formula fixture contains an image region with superscript, subscript, fraction-like notation, Greek letters, and an integral expression. The production upload path did not create `FormulaBlock` rows for this PDF image region:

- `FORMULA_IMAGE_DETECTED`: false
- `FORMULA_TEXT_RECOGNIZED`: false
- `FORMULA_CONTEXT_LINKED`: false

The parse quality layer did raise a text-level formula signal, but that is not equivalent to image formula recognition.
