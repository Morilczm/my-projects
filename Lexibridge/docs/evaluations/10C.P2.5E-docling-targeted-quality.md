## Key Findings

Mixed-layout:

- Baseline produced one flat block.
- Docling produced six meaningful blocks with page and bbox data.
- Reading order was acceptable for this fixture.
- This is a real improvement for candidate-governance input shape.

Two-column:

- Docling preserved all anchors, but interleaved left and right column text in early body blocks.
- Example: a left-column Fourier Transform sentence was merged with a right-column Voltage Divider sentence.
- This caused one key reading-order error and fails the two-column gate.

Scanned bilingual:

- Docling recovered all six English/Chinese anchors in this synthetic scan.
- Unicode Chinese was preserved.
- Page and bbox were present on the content blocks.
- Baseline recall on the same fixture was 0.6667.

Table:

- Docling detected a table with 4 rows and 3 columns and preserved cell text.
- The reduced export also exposed many cell-text children without page/bbox, lowering total content bbox completeness to 0.0769 on this fixture and 0.8681 across Docling content blocks.
- This may be partly normalizer-specific, but it still fails the current gate because downstream provenance would be incomplete without additional mapping.

Formula:

- Baseline FormulaRegion detection found the raster formula region, with recognition unavailable.
- Docling preserved the surrounding text and OCR-like formula text as a paragraph, but did not distinguish it as a formula or image region in this probe.
- Formula structure recognition remains unavailable. No LaTeX success is claimed.

Negative sample:

- Docling did not hallucinate specialist terms.

## Recommended Routing Architecture

Do not implement this yet.

If Docling is later accepted after a follow-up quality repair/probe:

- simple born-digital PDFs -> current native parser
- simple scanned text PDFs -> current Tesseract OCR path
- complex layout, table-bearing, mixed-layout, or structure-risk PDFs -> Docling candidate path
- Docling unavailable or failed -> current baseline fail-soft fallback

Suggested complex-document signals:

- multi-column layout
- multiple image or table regions
- native parser produces one abnormal large block
- reading-order risk
- table presence
- mixed layout
- native extraction quality insufficient

## Limits

- This is still not parser selection.
- Docling was evaluated only on seven synthetic targeted fixtures.
- The table result needs better export normalization before downstream provenance can be trusted.
- Two-column routing remains risky until the reading-order issue is understood.
- Formula image detection remains better covered by LexiBridge FormulaRegion than by this Docling probe.
- Formula structure recognition is not closed.
