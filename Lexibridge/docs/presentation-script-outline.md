# Presentation Script Outline

## 1. Opening

Explain why bilingual terminology matters in transnational education.

## 2. Midterm Problem

The early version was too close to a translation website and did not solve evidence, course context, or teacher trust.

## 3. Problem Redefinition

项目方向从“翻译网站”转变为“课程知识对齐平台”，体现了问题定义的深化和设计思维中的迭代过程。

## 4. Core Workflow

Teacher uploads English and Chinese materials. The system parses text, performs OCR, builds a course KB, retrieves evidence, aligns terminology, generates cards, and sends risky cards to QC.

## 5. Course Knowledge

The project uses course documents and Chinese references rather than relying only on generic AI responses.

## 6. Computational Thinking

Discuss decomposition, abstraction, scoring algorithms, state machine, evaluation harness, and regression tests.

## 7. Design Thinking

Discuss student needs, teacher workload, prototype testing, feedback, and iteration.

## 8. Demo

Show teacher upload/QC, student search/evidence/feedback, admin evaluation and diagnostics.

## 9. Evaluation And Feedback Loop

Show EvaluationRun, retrieval regression, PilotFeedback, and IterationBacklog.

## 10. Limitations

Local pilot-ready only. Not production deployment. Not every card is guaranteed correct.

## 11. Next Plan

Small real-course pilot, teacher-reviewed gold set, production data and storage migration.

## 12. Closing

The mature part of the project is not a single AI answer. It is the governed workflow: evidence, risk, teacher review, evaluation, and iteration.
