## 10. Key Analysis

| Question | Answer |
|---|---|
| Is 0.8% the current true coverage? | Not in current mainline DB. It is the historical 10G second-course aggregate, `2/250`. |
| What is explicit pair extraction coverage? | Historical second-course strict detection was 20 detected pairs from 137 raw text-layer hints. Current mainline cannot recompute this. |
| How much pair-to-selected-item loss exists? | Historical 10G: 18/20 accepted pairs did not match selected Items. Current mainline cannot validate item identities. |
| How much eligibility loss exists? | Historical 10F: 20/20 detected pairs rejected; historical 10G: 0/20 rejected after pair-local repair. Current mainline does not include that repair. |
| What proportion truly needs Provider generation? | Current data cannot prove. Historical upper bound after explicit evidence was 248/250 Items without Chinese candidate, but some may be noise or should abstain. |
| How much can document-local matching improve? | Historical maximum from already accepted pairs is 18 additional Items, or 7.2% of 250, if those accepted English surfaces are valid selected concepts. This is not proven without item-level traces. |
| What could Provider theoretically cover? | At most Items that are valid concepts, have enough English context, pass redaction, and are not noise/fragment/ambiguous. Current DB cannot estimate that subset. |
| Which Items should abstain? | URL/header/footer/noise, fragments, single-symbol/undefined abbreviations, ambiguous terms without context, and Items lacking provenance should abstain rather than receive forced Chinese candidates. |

## 12. Three Highest-Value Next Interventions

1. Reconstruct a reproducible isolated coverage dataset from safe local PDFs and
   current production flow, without writing the main DB.
2. Preserve item-level funnel artifacts for pair detection, eligibility,
   selected matching, evidence persistence, candidate persistence, and final
   blocker status.
3. Only after a nonzero reproducible denominator exists, decide between
   non-Provider matching repair, Provider Proposal evaluation, or abstention
   policy.
