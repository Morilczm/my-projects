# SP101 信号处理基础 - 中文参考资料

傅里叶变换用于将时域信号表示为频率分量，也可称为频域表示。

卷积描述两个信号经过积分叠加后形成第三个信号，常用于线性时不变系统分析。

角频率表示单位时间内相位变化的弧度数，单位通常为弧度每秒。

波长表示波在空间中重复一次的距离。

时域信号描述信号随时间变化的形式。

频域表示用频率分量描述信号内容。

采样定理说明带限信号可由高于最高频率两倍的采样率重建。

冲激响应描述系统在冲激输入下的输出。

传递函数表示变换域中系统输入与输出之间的关系。

拉普拉斯变换将时域函数转换为复频域函数。

带宽表示信号占用或系统支持的频率范围。

调制通过改变载波信号来传递信息。

载波频率是承载调制信号的中心频率。

信噪比比较有用信号功率与噪声功率。

相移表示波形在相位上的位移。

幅度表示信号的大小或强度。

频率响应描述系统对不同频率输入的响应。

Z 变换将离散时间信号转换为复频域表示。

低通滤波器通过低频并衰减高频。

高通滤波器通过高频并衰减低频。
