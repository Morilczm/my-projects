# MATH101 工程数学 - 中文参考资料

矩阵是按行和列排列的数或符号的矩形数组。

特征值是满足 Ax = λx 的标量 λ，其中 x 是非零特征向量。

特征向量是在线性变换后方向保持不变的非零向量。

微分方程描述函数与其导数之间的关系。

积分表示累积量或曲线下的面积。

导数表示函数的瞬时变化率。

梯度是由偏导数组成的向量，指向函数增长最快的方向。

概率密度函数描述连续随机变量的概率分布。

线性变换保持向量加法和数乘结构。

极限描述自变量趋近某点时函数值趋近的量。

向量空间是在加法和数乘下封闭的向量集合。

行列式是与方阵相关的标量。

秩表示矩阵列空间或行空间的维数。

正交表示两个向量内积为零。

基是一组线性无关且张成向量空间的向量。

偏导数是多元函数对某一个变量的导数。

泰勒级数使用某点处的导数来近似函数。

复数包含实部和虚部。

范数衡量向量的长度或大小。

内积推广了点积并衡量向量相似性。
