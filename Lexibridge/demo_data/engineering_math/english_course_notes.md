# MATH101 Engineering Mathematics - English Course Notes

Matrix is a rectangular array of numbers or symbols arranged in rows and columns.

Eigenvalue is a scalar λ such that Ax = λx for a nonzero eigenvector x.

Eigenvector is a nonzero vector whose direction is preserved by a linear transformation.

Differential Equation relates a function to its derivatives.

Integral represents accumulation and area under a curve.

Derivative measures the instantaneous rate of change of a function.

Gradient is a vector of partial derivatives that points in the direction of greatest increase.

Probability Density Function describes the likelihood distribution of a continuous random variable.

Linear Transformation maps vectors while preserving vector addition and scalar multiplication.

Limit describes the value approached by a function as the input approaches a point.

Vector Space is a set of vectors closed under addition and scalar multiplication.

Determinant is a scalar value associated with a square matrix.

Rank is the dimension of the column space or row space of a matrix.

Orthogonality means two vectors have zero inner product.

Basis is a set of linearly independent vectors that spans a vector space.

Partial Derivative differentiates a multivariable function with respect to one variable.

Taylor Series approximates a function using derivatives at a point.

Complex Number has a real part and an imaginary part.

Norm measures the length or magnitude of a vector.

Inner Product generalizes dot product and measures vector similarity.

Formula samples include ∫_0^∞ e^{-x^2} dx = √π / 2, Ax = λx, and dy/dx = f(x, y).
