# DS101 数据结构与算法 - 中文参考资料

哈希表，也称散列表，通过哈希函数将关键字映射到桶或存储位置，常用于快速查找、插入和删除。

冲突解决用于处理多个关键字映射到同一位置的情况，常见方法包括链地址法和开放定址法。

二叉搜索树按照有序关系组织左右子节点，左子树关键字较小，右子树关键字较大。

栈遵循后进先出的访问原则，入栈插入元素，出栈移除最近插入的元素。

队列遵循先进先出的访问原则，入队插入元素，出队移除最早插入的元素。

链表由节点和引用组成，单向链表中每个节点指向下一个节点。

图由顶点和边组成，可用于表示网络、依赖关系和连接关系。

深度优先搜索沿着分支尽可能深入探索，然后回溯。

广度优先搜索先访问当前深度的所有相邻顶点，再进入下一层。

时间复杂度描述算法运行时间随输入规模增长的变化趋势。

空间复杂度描述算法内存使用量随输入规模增长的变化趋势。

堆是一种保持优先级关系的树形结构。

优先队列根据优先级而不是插入顺序移除元素。

递归通过在较小子问题上调用自身来求解问题。

动态规划保存重叠子问题的结果以避免重复计算。

贪心算法在每一步做出局部最优选择。

平衡树保持较小高度以保证操作效率。

邻接表将图的边存储为每个顶点关联的列表。

邻接矩阵使用以顶点为索引的矩阵存储图的边。

拓扑排序对有向无环图中的顶点排序，使前置依赖先出现。
