# DS101 Data Structures and Algorithms - English Course Notes

Hash Table maps keys to buckets using a hash function. Hash tables support efficient average-case lookup, insertion, and deletion.

Collision Resolution handles cases where multiple keys map to the same bucket. Separate chaining and open addressing are common strategies.

Binary Search Tree stores ordered keys with left and right child nodes. The left subtree contains smaller keys and the right subtree contains larger keys.

Stack follows the last-in first-out principle. Push inserts an element and pop removes the most recently inserted element.

Queue follows the first-in first-out principle. Enqueue inserts an element and dequeue removes the earliest inserted element.

Linked List stores elements as nodes connected by references. A singly linked list points from each node to the next node.

Graph consists of vertices and edges. Graphs can represent networks, dependencies, and relationships.

Depth-first Search explores as far as possible along each branch before backtracking.

Breadth-first Search explores all neighbors at the current depth before moving to the next depth.

Time Complexity describes how running time grows with input size.

Space Complexity describes how memory usage grows with input size.

Heap is a tree-based structure that maintains a priority order.

Priority Queue removes elements according to priority rather than insertion order.

Recursion solves a problem by calling the same procedure on smaller subproblems.

Dynamic Programming stores results of overlapping subproblems to avoid repeated work.

Greedy Algorithm makes a locally optimal choice at each step.

Balanced Tree keeps height small to guarantee efficient operations.

Adjacency List stores graph edges as lists attached to each vertex.

Adjacency Matrix stores graph edges in a matrix indexed by vertices.

Topological Sort orders directed acyclic graph vertices so that each prerequisite appears first.
