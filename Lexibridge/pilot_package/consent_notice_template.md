# Pilot Consent Notice Template

This pilot evaluates a local course terminology support system. Participation involves using the system to search terms, view evidence, mark learning status, and optionally submit feedback.

The system may record usage actions, feedback, job status, and terminology interactions. Personal uploads remain private to the student account and are not added to the course public knowledge base by default.

The system output is for learning support and should be interpreted with evidence, risk notes, and teacher review status. It is not a final answer source.

Participants may report concerns to the pilot owner or teacher during the pilot.
