# Demo Data vs Real Pilot

## Demo Data

- Self-authored materials.
- Controlled terms and negative examples.
- Stable for demonstration.
- Useful for regression tests.
- Does not represent full real-course complexity.

## Real Pilot

- Teacher-provided real materials.
- Real student search behavior.
- Real OCR noise.
- Real terminology ambiguity.
- Requires authorization review.
- Requires teacher review and feedback loop.

Demo success does not equal full real-course success. Real pilots must continue validation through Evaluation, PilotFeedback, teacher review, retrieval regression, and iteration backlog.
