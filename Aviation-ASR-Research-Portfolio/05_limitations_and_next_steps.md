# 局限与后续工作

## 已知局限

1. 数据来自结构化航空英语课程录音和课程预期读法，不能直接代表真实空管无线电流量。
2. `transcription_n` 和 canonical reference 是课程生成/整理文本，不等同于逐条人工听写金标准。
3. 实体 P/R/F1 由固定规则解析，受关键词、数字读法、单位和范围规则影响，不是独立人工 NER 评测。
4. 任务一 LoRA 的整体 WER 改善伴随实体 precision 和 F1 下降，呼号误报是突出问题。
5. 任务二的 T5 不能可靠修复上游 ASR 已经删除或替换的实体；gate 只能约束候选改写。
6. 任务一和任务二都保留了 test 使用和异常恢复的审计记录，不能把结果描述为完全无接触、无异常的一次性实验。
7. 作品集没有包含模型和音频，因此脱离集群后只能阅读、复核轻量结果，不能直接进行完整推理。

## 后续工作

- 对呼号和数值实体加入更可靠的人工抽检与声学复核。
- 将实体错误按删除、替换、幻觉和单位混淆分别建模，避免只优化 WER。
- 在 dev 上固定预算，比较实体加权、辅助目标和 conservative decoding，报告 precision/recall trade-off。
- 继续保留 oracle、baseline ASR 和 task1 ASR 三种恢复输入，定位上游噪声传播。
- 对长输入、超预算样本和技术失败建立独立的预检与回退协议。
- 在统一 GPU、统一预处理和不接触 test 的条件下补充端到端延迟与显存评估。
