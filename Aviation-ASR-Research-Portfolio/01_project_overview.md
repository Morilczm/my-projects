# 项目概览

## 研究问题

航空通话同时包含普通英语和呼号、跑道、航向、频率、距离、时间、飞行高度层等关键实体。相同内容在 spoken-form 和书面 canonical 形式之间存在明显差异，例如：

```text
one one niner decimal seven -> 119.7
runway zero two right      -> RWY 02R
```

系统需要回答两个不同问题：模型是否听对了，以及听到的内容能否被安全地恢复成规范形式。把两个阶段拆开，才能观察 ASR 错误如何传播到文本恢复。

## 项目路线

1. 使用航空领域 Whisper 基模完成 spoken-form baseline。
2. 在 Decoder 注意力投影上加入 LoRA，保持推理输出空间不变。
3. 用训练参考文本中的规则匹配生成弱实体标签，审计数据与分析关键实体；个人正式 LoRA 训练未加入实体辅助损失。
4. 使用 Flan-T5 和 legacy aviation rules 比较 spoken-to-canonical 恢复。
5. 在 oracle spoken、基模 ASR、任务一 ASR 三种输入下评估恢复模块。
6. 用 WER、Exact、实体 P/R/F1、实体删除/新增和错误案例共同审计系统。

## 个人成果范围

本目录对应服务器 `run/czm` 的个人实验提交，包含任务一完整 dev/test 评估和任务二完整训练、dev 选择、test 及恢复核验。论文中的完整 58,507 条录音结果属于项目背景和参考研究，不能与本作品集中的 12,000/1,200/1,200 子集结果混写。

## 作品集亮点

- 将语音识别与文本规范化拆成可诊断的两阶段流水线。
- 用参数高效的 Decoder LoRA 在有限 GPU 资源下进行领域适配。
- 单独检查呼号、跑道、航向等实体，发现总体 WER 改善与实体精度下降并存。
- 对规则、T5 原始输出和带 gate 的回退输出进行同输入条件比较。
- 保存配置、预测、哈希、错误案例和恢复说明，使结果能够被复核。
