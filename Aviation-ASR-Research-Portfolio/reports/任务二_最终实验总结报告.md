## 1. 主要结论

**依据 dev 预先选定的主系统为“任务一 ASR＋已有规则”。** 最终 test WER 为 **54.73%**，Exact 为 **33.92%**，canonical 实体 micro F1 为 **48.93%**。

T5 从正确 spoken 学会了多数书面转换，但仍有数值替换、合并、实体删除。检查与回退改善实体保留，却使最终输出很接近保守规则。ASR 中已有的错误呼号与漏失内容，不能由输入一致性检查可靠消除。

## 2. 数据、模型与训练

| 项目 | 实际配置 |
|---|---|
| 数据 | 冻结 train 12,000 / dev 1,200 / test 1,200；沿用原划分 |
| 训练目标 | 同行 transcription_n → canonical_target(excel_original_text) |
| 输入模式 | oracle、baseline-ASR、task1-ASR 分开评估 |
| 文本模型 | google/flan-t5-base，revision 7bcac572ce56db69c1ea7c8af255c5d7c9672fc2 |
| 训练 | 从基模初始化全参数微调，1 epoch，1,500 步，seed 42 |
| batch / optimizer | micro-batch 4、累积 2；AdamW，lr 1e-4、weight decay 0.01、clip 1.0 |
| 精度 | fp32 权重，训练 bf16 autocast；生成 float32 |
| 生成 | greedy、num_beams=1、do_sample=false、max_new_tokens=192，batch 4 |
| 输入预算 | 包含 prompt 最多 256 token；不截断 |
| 训练 label | 保留小数点、前导零、代码及内部标点；复用旧五类占位符清理 |

原任务一只生成 spoken 文本；T5 是独立文本模型，不加载 Whisper adapter。小训练作业 168554 先验证 64 条/8 步和独立重载；正式训练从固定基模重新初始化，不接续小训练权重。

原有五类占位符为 call sign、control unit、location、waypoint、navaid。其他括号保留内容，斜杠按旧规则展开为 or，残留元数据和单位写法是已披露的标签噪声。train 的 RWY 02R/RWY02R 格式冲突原样保留。呼号代码仅由 train 配对推导；china star 存在代码冲突而未启用。

设 G 为参考实体、P 为预测实体、S 为保守规则投影的输入实体。上述四个比例分别为 Σ|G−P|/Σ|G|、Σ|P−G|/Σ|P|、Σ|S−P|/Σ|S|、Σ|P−(S∪G)|/Σ|P−S|。分母为0记—，不是0。S 的覆盖有限，是代理指标；参考仅用于评分，不进入推理或 gate。

gate 要求候选的有序内容和实体集合与保守规则一致，不满足就回退。因此 guarded 的实体结果被该约束限制，不能单独用其 F1 衡量模型的独立贡献。全部系统的13类实体计数见 test_entity_metrics.csv。

## 6. 最终 test 失败与技术恢复披露

作业169151在GPU上完成了oracle的1,200条生成及四份结果；随后发现baseline第526条含prompt共285 token，超过已冻结的256上限，于进入该模式前主动中止。Task1-ASR最大205 token、没有超限。

原脚本还错误地将marker显示为config目录，实际写在原运行目录。本次保留原marker、失败作业与原oracle文件；恢复作业169202新建单独marker，四份oracle按已记录SHA-256逐字节复用，未重复生成。

恢复仍采用256上限，不截断、不扩容：baseline第526条未调用T5，raw预测为空并标记技术失败；guarded使用冻结保守规则回退；legacy主恢复器正常处理完整输入。该行保留在全部1,200条的所有评分分母中。Raw/guarded的baseline技术失败计数各为1，其他模式无此异常。

**这是接触test后的异常处理协议补充，不能声称完全遵循原始一次成功运行协议。** 模型、checkpoint、主系统、规则、gate及正常行解码设置未变；没有依据test质量选择方案。超长行的raw分数是含技术失败的全量结果，不伪装为1,200条全部成功生成。

## 8. 错误分析与局限

20个任务二dev案例随本报告归档；与此前任务一的10例共同组成项目错误分析记录。它们是不同dev记录，不是20种互相独立的新根因，且均未听音。案例中的“词错误更少”不意味着实体正确或gate误拒绝；有些较低WER候选同时把heading220改为230。

原始T5可能合并风向/速度数字，规则无法辨别ASR输入内的错误呼号。课程预期读法不等于逐条人工听写参考。canonical normalize_eval 会去除小数点，故实体必须在未去标点文本上解析；这些规则指标不是人工NER金标准。

任务一已存在历史test使用（基模161294、LoRA167945）；本次复用其ASR结果。任务二主系统选择依据dev，本报告保留test上不同指标的取舍，不按test重新排名选择或追加训练。
