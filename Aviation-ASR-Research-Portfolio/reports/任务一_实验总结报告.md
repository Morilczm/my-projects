## 摘要

本实验基于已有航空领域模型 `whisper-large-v3-atco2-asr`，使用冻结的 12,000 条训练数据进行一轮 decoder-only LoRA 适配，冻结基模权重和 Encoder LoRA，仅更新 Decoder 注意力投影的低秩参数。完成 baseline、小规模训练及重载验证、正式训练、完整 dev 对照、实体指标计算、10 个 dev 错误的分类分析和一次正式 LoRA 最终 test 推理。

完整 dev 上，spoken WER 从 47.29% 降至 43.29%，整句 Exact 从 21.67% 提高至 29.00%。完整 test 上，WER 从 60.34% 降至 50.14%，相对下降 16.91%；Exact 从 22.75% 提高至 34.25%，净增加 138 条完全正确转写。

但改进存在明确代价：完整 test 的实体 micro Recall 从 37.84% 提高至 43.04%，Precision 从 96.30% 降至 50.61%，F1 从 54.33% 降至 46.52%。dev 中发现固定呼号 EXO321 在多种不同参考文本中重复出现，说明空输出减少并不等于关键信息恢复。结论是普通 LoRA 改善了总体转写指标，但没有全面提高实体保留能力，尤其需要控制呼号误报。

### 2.2 模型结构

Whisper 具有 32 层 Encoder 和 32 层 Decoder，隐藏维度 1280，20 个注意力头，FFN 中间维度 5120，输入为 16 kHz 单声道音频提取的 128 维 log-Mel 特征。基模原始参数冻结。

每个 Decoder 层的 self-attention 和 cross-attention 均在 `q_proj`、`k_proj`、`v_proj`、`out_proj` 上加入 LoRA，共 32×2×4=256 个可训练 LoRA 模块。每个模块 A 为 8×1280、B 为 1280×8，推理时有效权重为 `W0 + (16/8) BA`。总可训练参数为 5,242,880，约占日志报告总参数量的 0.34%。

实现上先向匹配投影安装 LoRA，再冻结 Encoder 的 128 个 LoRA 模块；它们仍存在于保存结构中，但不参与更新。Decoder 的原始权重、词嵌入、LayerNorm、FFN 和词表投影均保持冻结。本实验没有实体辅助分类头。

## 3. 评估协议与 test 使用披露

ASR 使用相同评估器、音频预处理和英文 transcription prompt，greedy 解码（num_beams=1），max_new_tokens=128，no_repeat_ngram_size=0，fp16，不给生成过程提供参考转写。训练为 teacher forcing，评估为自由生成，两者用途不同。

spoken WER 按所有参考词的总数计算 corpus WER，而不是平均逐句 WER；Exact 为相同规范化后的整句完全匹配率。规范化进行小写转换、字符清理和空白合并。空预测保留在指标分母中，技术失败单独记录；不删除模型表现不佳的行。

### 3.1 实体指标定义

固定复用 `atc_entity_rules.py` 从原始 `transcription_n` 和保存的规范化 hypothesis 提取实体。逐句以“实体类型＋canonical_hint 规范值”集合匹配，同句相同值去重，不跨句匹配，也不评价字符边界。

```text
TP = |参考实体 ∩ 预测实体|
FP = |预测实体 − 参考实体|
FN = |参考实体 − 预测实体|
Precision = TP / (TP + FP)
Recall    = TP / (TP + FN)
F1        = 2TP / (2TP + FP + FN)
```

主指标对全部 1,200 条计数，包括参考未提取到实体的句子中的预测 FP。另报“仅参考实体阳性句子”的兼容口径，以对应仓库主表函数；不得混用两个范围。各类 TP/FP/FN 累加得到 micro 指标，不取分类 F1 的算术平均。分母为零记 null/—；有错误但 TP=0 时 F1=0。Support 是逐句去重后的参考实体值数。

规则参考不是人工 NER 标注。呼号只覆盖已有 9 个前缀：air cruiser, blue nova, chase air, china star, exo, kingfisher, orbit air, ornate, zenith。未解析到实体不等于音频或文本没有实体，规则还存在关键词、单位、数字读法及范围校验限制。全部模型使用同一冻结规则，未根据 test 修改映射。

### 4.2 关键工程工作

1. 从 train 的 transcription_n 生成 12,000 条规则弱标签，3,510 条含实体，共 4,900 个 span；完成逐行身份和 token 对齐审计。本轮弱标签用于现有训练器的数据检查，没有增加实体监督损失。
2. 修复训练 decoder 起始 ID 与生成配置不一致：起始 token 对齐至 50258，使用英语、转写、无时间戳前缀 `[50258,50259,50360,50364]`，并检查标签右移和损失对齐；保留个人训练器及修改记录，未覆盖共享基模文件。
3. 先用 64 条 train 做 8 步调试，验证梯度、冻结范围、adapter 保存和独立重载。相同 dev 前 100 条 WER 50.45%→48.72%，Exact 13→14；这仅作为流程证据，不与完整 dev 混比。
4. 正式训练从基模重新初始化 LoRA，没有接续调试 adapter。作业 163783 正常结束，累计平均 loss=0.9696，完成 1,500 个优化步；训练 loss 不能替代识别质量指标。
5. 正式 adapter 完整 dev 评估前通过权重审计，256 个 Decoder LoRA 模块均有非零有效增量，Encoder LoRA 保持冻结。全部正式 dev/test 预测技术失败数为零。

## 9. 结论、限制与后续方向

本轮完成了规定的实验链路和交付材料。单轮普通 decoder LoRA 在 dev 和 test 均降低 spoken WER、提高整句 Exact，但实体指标揭示了明显的误报代价。test 中额外 25 个实体 TP 不足以抵消额外 195 个 FP，尤其呼号误报使整体 F1 下降。因而结果支持“转写层面有效、实体层面存在取舍”，不支持“所有航空关键信息更可靠”或生产可用的结论。

主要限制包括单次训练 seed、无多种子统计或显著性检验、没有周期 checkpoint、规则参考及样本覆盖有限、未听音确认错误根因、历史基模权重哈希缺失、效率计时范围不同，以及沿用评估器的长音频截断问题。dev/test 实体类别分布也不同，不能把两个划分的绝对分数差异直接归因于模型变化。论文指标不与本次子集混作公平对照。

后续若另开研究实验，应优先在 train/dev 核验音频和模板化输出，再做学习率、训练步数、完整实体 span 加权等单因素对照，必要时补充按类型均衡的人工核验集。这些是未执行的建议；本次最终 test 结果冻结，不再用于调参，也不覆盖现有报告。
