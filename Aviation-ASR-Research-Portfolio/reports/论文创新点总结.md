# 论文创新点总结

## 一、总体定位

本工作的创新性主要体现在**面向航空通话转录的两阶段系统设计、参数高效领域适配、关键实体风险分析，以及对 ASR 噪声下文本规范化能力的分层实证评估**。现有实验不足以支持“提出了全新的模型结构或训练算法”这一表述；更稳妥的定位是：围绕航空语音到规范文本的实际流程，完成了可复现的系统化实验，并得出具有任务针对性的经验结论。

## 二、主要创新点

### 1. 将航空语音处理拆分为“语音识别—文本规范化”两阶段

工作把端到端目标分解为两个具有不同输入、输出和错误来源的子任务：

1. 任务一：从音频生成航空通话的 spoken-form 转写；
2. 任务二：将 spoken-form 转为 canonical 书面形式，例如将口语数字表达恢复成频率或其他标准写法。

这一设计允许分别观察声学识别错误与文本恢复错误，并通过 oracle spoken、基模 ASR 和任务一 ASR 等输入条件，分析上游噪声如何影响下游规范化。它使系统性能诊断比只报告单一端到端分数更具可解释性。

### 2. 在航空 Whisper 模型上验证 Decoder-only LoRA 适配

任务一在航空领域 Whisper 基模上冻结原始模型参数，仅对 Decoder 的 self-attention 与 cross-attention 中 q/k/v/out 投影加入 LoRA。rank 为 8、alpha 为 16、dropout 为 0.05，可训练参数约 524 万，仅占模型参数约 0.34%。

在一轮训练、有限算力的设置下，测试集 spoken WER 从 60.34% 降至 50.14%，Exact 从 22.75% 提高至 34.25%。该结果说明，较小规模的生成端适配可以改善航空通话的整体转写表现，为资源受限条件下的领域适配提供了实证参考。

### 3. 以关键实体为独立维度，揭示总体识别改善与安全相关信息可靠性之间的落差

工作没有仅以 WER 代表系统质量，而是同时报告 Exact 和呼号、跑道、航向等实体指标。任务一测试集上，LoRA 虽降低了整体 WER，但实体 micro F1 从 54.33% 降至 46.52%，Precision 从 96.30% 降至 50.61%；呼号误报是实体精确率下降的主要来源。

这一发现构成了本工作的关键经验贡献：在航空通话这类高风险语境中，整体转写更接近参考文本，并不意味着关键字段更可信。因而模型评估和后续优化需要把实体误报、实体删除等错误与普通词错误分开考察。

### 4. 评估文本规范化模型对 ASR 噪声的敏感性，并比较生成、门控与规则方案

任务二采用独立的 FLAN-T5-base 文本模型学习 spoken-to-canonical 映射，并把模型 raw 输出、检查与规则回退的 guarded 输出，以及已有规则放在相同输入和指标下比较。实验分别覆盖正确 spoken、基模 ASR 和任务一 ASR 输入，从而将理想输入下的恢复能力与真实串联系统中的抗噪能力区分开来。

在正确 spoken 测试输入上，训练后的 T5 能有效学习规范化；但在任务一 ASR 输入上，开发集 WER 为 47.03%，略高于已有规则的 46.67%，实体 F1 也明显较低（52.02% 对 68.62%）。据此按开发集预先冻结主方案为“任务一 ASR + 已有规则”。测试集上 T5+gate 与规则各有指标取舍，因此没有根据 test 重新选择系统。

这组对照表明，规范化模型的能力不能只在干净输入下评价；上游识别噪声、模型自由改写倾向和回退机制都影响最终表现。门控与回退能够限制部分不可靠改写，但也可能使输出趋于保守，无法自动修复输入中已经发生的错误。

### 5. 把实体删除、新增和输入一致性纳入规范化分析

任务二不仅报告 WER、Exact 和实体 F1，也统计实体删除、新增及回退相关行为，并检查原始输入、候选输出和规则投影之间的一致性。这样的分析有助于区分几种看似相近但含义不同的情况：模型是否漏掉已有实体、是否凭空引入实体，以及门控是否把候选退回规则结果。

该分析揭示了一个实际边界：文本规范化模型可以学习格式映射，但在缺少声学证据时，难以判定 ASR 已经识别错的呼号或数值究竟应该如何修复。保留输入实体可以控制删除，却不能保证输入实体本身正确。

### 6. 提供包含异常恢复与复算证据的可审计实验记录

两阶段实验保留了训练参数、模型版本、作业记录、逐条预测、指标定义和错误案例。任务二最终测试遇到超过冻结输入预算的样本后，报告披露了中止、恢复、oracle 结果哈希复用、异常行处理方式及其仍计入评分分母的事实；此外还进行了独立指标复算。

这不是模型算法创新，但属于实验方法与结果可信度方面的贡献：明确区分模型表现、技术失败和恢复流程，避免把异常处理隐藏在汇总分数中，也便于后续复现和审查。

## 三、可直接用于论文或汇报的精炼表述

> 本工作围绕航空通话从音频转写到规范文本恢复的流程，构建并分层评估了“Whisper 领域适配—文本规范化”两阶段方案。任务一通过仅更新 Decoder 注意力投影的 LoRA，在约 0.34% 可训练参数的条件下改善了整体 spoken 转写指标；同时，实体级评价揭示了 WER 改善与呼号等关键实体可靠性之间的差异。任务二进一步比较了独立 T5 规范化模型、门控回退策略与规则基线，并在 oracle、基模 ASR 和任务一 ASR 输入下分析上游噪声传播。实验表明，干净文本上的规范化能力不能直接代表串联系统效果，关键实体的误报、删除和输入错误传播需要作为独立评价目标。工作还提供了对测试异常、恢复策略和指标复算的透明记录。

## 四、创新性表述的边界

- **可以强调：** 两阶段问题分解、航空领域 Decoder-only LoRA 的实证、关键实体风险揭示、不同噪声输入条件下的规范化比较、错误与技术异常的可审计分析。
- **不宜声称：** 提出了全新的 LoRA 算法、全新的 T5 架构、建立了新的航空语音基准，或已经解决了呼号识别与 ASR 噪声传播问题。
- **需要限定：** 实体指标由固定规则解析，不是人工金标准；报告中的错误案例基于文本，未逐条回听音频；最终测试异常已披露，因此应准确说明其处理协议。

## 五、一句话概括

**本工作的核心贡献，是用两阶段实验和实体级评价说明：航空语音系统的整体转写改善并不等于关键航空信息更可靠，而文本规范化模型在真实 ASR 噪声下也需要与规则、门控和明确的失败处理机制共同评估。**
