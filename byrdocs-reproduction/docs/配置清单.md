# 配置清单

这个文件只记录配置项**名称和位置**，不保存任何真实密钥。主站完整配置以 `source/byrdocs-main-c90f42d.zip` 内的 `wrangler.toml` 和源码为准。

| 项目 | 本次值或设置位置 | 用途 |
| --- | --- | --- |
| `name` | `byrdocs` | Cloudflare Worker 名称。 |
| D1 `binding` | `DB` | Worker 数据库绑定。 |
| D1 `database_name` | `byrdocs` | 数据库名称。 |
| D1 `database_id` | `ac16ab3a-5112-4da1-9635-8f995738144c` | 当前账号的 D1 ID；换账号必须替换。 |
| `OSS_ENDPOINT` | `https://oss-cn-beijing.aliyuncs.com` | OSS S3 兼容 API Endpoint。 |
| `OSS_REGION` | `cn-beijing` | Worker 签名使用的 Region。 |
| `OSS_FILE_BUCKET` | `byrdocs-file` | PDF、ZIP、JPG、WEBP。 |
| `OSS_DATA_BUCKET` | `byrdocs-data` | JSON/YAML 数据。 |
| `OSS_ACCESS_KEY_ID` | Cloudflare Worker Secret | RAM 用户访问密钥 ID。 |
| `OSS_ACCESS_KEY_SECRET` | Cloudflare Worker Secret | RAM 用户访问密钥 Secret。 |
| 本地 ossutil Region | `oss-cn-beijing` | ossutil 的阿里云地域格式。 |
| 本地 ossutil 凭据 | 本机 ossutil 配置文件 | 本地上传权限；此归档不包含配置文件。 |

主站还有 `JWT_SECRET`、`BYRDOCS_SITE_TOKEN`、GitHub OAuth 等运行时或构建时设置。它们与 OSS 改造不同，是否需要取决于启用的登录、投稿、Publish 等功能；不要把实际值写进本目录。`.env` 与 `.dev.vars` 只应存在于本地忽略文件或平台 Secret 中。

**部署位置：**普通 OSS Endpoint、Region、桶名在 `wrangler.toml` 的 `[vars]`；两个 OSS AccessKey 在 Cloudflare Workers 的 Secrets。GitHub Actions 若以后改为自动上传 OSS，也需要在 GitHub Secrets 中另配有最小权限的凭据，但现有 Archive Actions 仍使用 R2，当前没有完成 OSS 自动化。
